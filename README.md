# نغمه · آرشیو شنیدن عمیق

آرشیو شخصی و پخش‌کنندهٔ باکیفیت برای موسیقی سنتی ایران و موسیقی کلاسیک، مخصوص اندروید.

- **بشنو**: خانه‌ای آرام با ادامهٔ شنیدن، علاقه‌مندی‌ها و آمار شنیدن
- **آرشیو**: هنرمندان، آثار (دستگاه، آواز، گوشه، اپوس)، قطعه‌ها، آلبوم‌ها و مجموعه‌ها
- **کهکشان**: نقشهٔ سه‌بعدی پیوند هنرمندان؛ هر هنرمند یک ستاره، هر پیوند یک رشتهٔ نور
- **پخش‌کننده**: FLAC، WAV، ALAC، MP3، OGG، Opus و DSD سونی (DSF/DFF) با کنترل از صفحهٔ قفل
- **شنیدن عمیق**: متن هم‌گام (LRC)، اعتبار نوازندگان، نت (تصویر و متن)، گالری، زندگی‌نامه، یادداشت
- **اشتراک**: بستهٔ سبک آرشیو (بدون فایل صوتی) برای دوستان

## گرفتن فایل APK فقط با گوشی

### راه ۱ (ساده‌ترین): سپردن به یک ایجنت
فایل zip همین پروژه را به ایجنتی که به گیت‌هاب دسترسی دارد (مثلاً Replit Agent) بده و بگو:
> «محتوای این zip را بدون تغییر در یک ریپوی تازهٔ گیت‌هاب به نام naghme-app روی شاخهٔ main پوش کن. پوشهٔ ‎.github‎ هم حتماً پوش شود.»

بعد برو سراغ «دانلود APK» در پایین.

### راه ۲: خودت، فقط با مرورگر گوشی
1. در مرورگر گوشی وارد github.com شو (اگر حساب نداری، Sign up).
2. بالای صفحه **+** و بعد **New repository**. نام: `naghme-app`. گزینهٔ **Public** و تیک **Add a README** را بزن. **Create repository**.
3. در صفحهٔ ریپو: **Add file** ← **Upload files** ← فایل `naghme.zip` را انتخاب کن ← **Commit changes**.
4. دوباره **Add file** ← **Create new file**. در کادر نام دقیقاً بنویس:
   `.github/workflows/unpack.yml`
   و متن زیر را کامل در بدنه‌اش کپی کن، بعد **Commit changes**:

```yaml
name: Unpack Naghme
on:
  push:
    paths: ['naghme.zip', '.github/workflows/unpack.yml']
  workflow_dispatch:
permissions:
  contents: write
  actions: write
jobs:
  unpack:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Unzip project
        run: |
          test -f naghme.zip || exit 0
          unzip -o naghme.zip
          rm naghme.zip
          git config user.name "naghme-bot"
          git config user.email "bot@users.noreply.github.com"
          git add -A
          git commit -m "Unpack Naghme" || exit 0
          git push
      - name: Start APK build
        env:
          GH_TOKEN: ${{ github.token }}
        run: gh workflow run build-apk.yml --ref main || true
```

5. حالا تب **Actions** را باز کن. اول «Unpack Naghme» اجرا می‌شود و بعد خودش «Build Naghme APK» را شروع می‌کند. ساخت حدود ۲۰ تا ۳۰ دقیقه طول می‌کشد.
   اگر Actions پیام «I understand… enable» نشان داد، اول آن را بزن.

### دانلود APK
1. در صفحهٔ اصلی ریپو، بخش **Releases** (یا آدرس `.../releases`) را باز کن.
2. آخرین نسخه، فایل `naghme-شماره.apk` را بزن تا دانلود شود.
3. فایل را باز کن. اگر اندروید اجازهٔ «نصب از منابع ناشناس» خواست، برای مرورگرت فعالش کن.
4. نصب کن و لذت ببر.

### به‌روزرسانی
هر بار فایلی در ریپو عوض شود، یک APK تازه ساخته می‌شود. نسخهٔ تازه را **روی همان قبلی** نصب کن؛ آرشیو و موسیقی‌هایت سر جایشان می‌مانند. (برنامه را حذف نکن، حذف یعنی پاک شدن آرشیو. قبلش از تنظیمات «ساخت بسته» بگیر.)
اگر ساخت خطا داد، در تب Actions روی مورد قرمز بزن و متن خطا را برای ایجنت بفرست.

## قالب‌های صوتی
| نوع | قالب‌ها |
|---|---|
| پخش مستقیم | FLAC، WAV، ALAC/M4A، AAC، MP3، OGG، Opus، MKA، WebM، 3GP، AMR |
| تبدیل یک‌باره به WAV ۲۴ بیتی | DSD سونی (DSF، DFF)، AIFF |
| فعلاً نه | DFF فشرده (DST)، APE، WavPack |

تبدیل DSD روی خود گوشی انجام می‌شود و برای هر دقیقه موسیقی چند ثانیه زمان می‌برد. کیفیت خروجی (۸۸.۲ یا ۴۴.۱ کیلوهرتز) در تنظیمات قابل انتخاب است.

## همراه هوشمند (اختیاری)
در تنظیمات می‌توانی کلید رایگان Gemini را از aistudio.google.com وارد کنی تا دربارهٔ دستگاه‌ها، آثار و هنرمندان آرشیوت گفت‌وگو کنی.

## برای توسعه‌دهنده‌ها
Expo SDK 54 · React Native 0.81 (New Architecture) · expo-router · Reanimated 4 · Skia (کهکشان) · expo-audio (Media3) · expo-sqlite.
ساختار: `app/` صفحه‌ها، `src/db` مدل داده و مخزن، `src/audio` پخش، ورود و تبدیل DSD، `src/galaxy` نقشهٔ کهکشان، `src/ui` اجزای رابط.

## تازه‌های این نسخه
- بومی‌سازی کامل واژه‌ها (جلد، ناشر، زندگی‌نامه، نگارخانه، گونه، رهبر ارکستر، شنیدن ژرف و…)؛ فقط قلم‌های فارسی: وزیر، لاله‌زار، نستعلیق.
- نقش‌مایه‌های ایرانی: رومیزی قلاب‌بافی، تور حاشیه، پردهٔ توری، گل‌سرخ دوازده‌پر تخت‌جمشید، حاشیهٔ فرش، ترنج، بته‌جقه.
- جابه‌جایی صفحه‌ها مثل ورق‌زدن کتاب فارسی، بالاآمدن پخش‌کننده، شکفتن گل زیر انگشت، رومیزی تپنده با صدا.
- تقویم خورشیدی و جشن‌های ایرانی، «برای این لحظه»، تاریخچهٔ شنیدن.
- کارگاه کارت‌پستال، پشتیبان کامل و بازگردانی (افزودن/جایگزینی)، انتخاب مدل Gemini، گفت‌وگوهای ذخیره‌شده.
